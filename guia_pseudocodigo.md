# Guía de Pseudocódigo — Para estudiar

## ¿Qué es pseudocódigo?
Es escribir la solución de un problema en pasos simples, en español, antes de programarlo. Ayuda a pensar la lógica sin pelearse con la sintaxis de un lenguaje.

## Reglas simples
- Usa "Si... entonces" y "Si no" para decisiones
- Indenta (sangría) lo que está "dentro" de una condición
- No uses símbolos de código, solo palabras claras
- Numera los pasos si ayuda a la claridad

---

## Ejemplo resuelto 1
**Problema:** Un cine cobra $8.000 la entrada. Si el cliente es estudiante, tiene 20% de descuento.

```
1. Preguntar el precio de la entrada
2. Preguntar si es estudiante
3. Si es estudiante:
     Calcular descuento = precio * 0.20
     Precio final = precio - descuento
   Si no:
     Precio final = precio
4. Mostrar el precio final
```

---

## Ejemplo resuelto 2
**Problema:** Una tienda da un premio si el cliente compra 5 productos o más.

```
1. Preguntar cuántos productos compró
2. Si compró 5 o más:
     Mostrar "¡Ganaste un premio!"
   Si no:
     Mostrar "Sigue comprando para ganar"
```

## Ejercicios para practicar (los mismos de clase)

**Ejercicio 1:** Un cine cobra $8.000 la entrada. Si el cliente es estudiante, tiene 20% de descuento. Escribe los pasos para calcular cuánto debe pagar.

**Ejercicio 2:** Una tienda da un premio si el cliente compra 5 productos o más. Escribe los pasos para decidir si aplica el premio.

**Ejercicio 3:** Un semáforo cambia de color cada cierto tiempo. Si está en rojo, los carros paran; si está en verde, avanzan; si está en amarillo, deben ir despacio. Escribe los pasos para esta lógica.

Elige UNO de estos 3 y tradúcelo a código Python real.
